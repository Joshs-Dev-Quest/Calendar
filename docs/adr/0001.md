# Project application: Calendar

## Context and Problem Statement
For the module DevOps there has to be choosen an small application on which the DevOps chain can be build arround.
The application selected for this need to be small without many features.
The focus of the project is a clean DevOps pipeline and not the application itself.The choosen application is a calendar application.

## Decision Drivers
- Already interested in a selfhosted calendar
- The Option authentik is probably to much out of the scope

## Considered Options
- Selfhosted Calendar
- Authentik automated management with ansible
- Lecturers proposed application

## Decision Outcome

Chosen option: "Selfhosted Calendar", because the calendar is an interesting project and not too big, if only basic functions are implemented.

### Consequences

- Good, because I can build on top of it when the module project is finished. 
- Bad, because could be maybe a bit more work than with a easy task list. I have to find a fitting GUI framework for python. I am running into danger to over engeenire the application.

# Clean documentation for the project with [Zensical](https://zensical.org/)

## Context and Problem Statement

For the module must be a clean documentation in the `docs` folder with specific files.
Because a clean documentation webpage is nice to look at and I can fullfill the module requirements and create a clean documentation website zensical fits in perfectly.

## Decision Drivers

- Learn how to cleanly automate and deploy a documentation website
- Test out a new documentation tool
- Give the project a cleaner touch

## Considered Options

- [Zensical](https://zensical.org/)
- [MKdocs](https://www.mkdocs.org/)
- [Sphinx](https://www.sphinx-doc.org/en/master/)

## Decision Outcome

Zensical is the winner because, MkDocs will be depreated soon and already shows error.
Sphinx may be also interesting, but I tried it a long time ago and I remember it to be a bit complicated and overkill for this project.

### Consequences

- Good, because Zensical is already installed and working as this is written. It's really easy to setup with a bit help of documentation and KI
- Bad, because a bit time is being lost for the setup. The focus driveds away from the goal of the module.
